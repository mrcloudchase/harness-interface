# Contributing

Open a pull request against `main`. CI runs the suite on both backends, the Docker tests, the
layer rule, lint, and a strict build of this documentation.

## Set up

```bash
git clone https://github.com/mrcloudchase/harness-interface && cd harness-interface
uv run --extra dev pytest                       # the unit suite: SQLite and a directory
uv run --extra dev pytest -m docker             # the Docker tests, with a daemon running
HI_TEST_POSTGRES=postgresql://… uv run --extra dev pytest    # also on Postgres
uvx ruff check --select F,E9 --target-version py311 .
uvx --from mkdocs-material mkdocs serve         # this documentation, live, at http://127.0.0.1:8000
```

`uv run harness-interface init --tenant acme --owner you` and `uv run harness-interface serve`
run the platform from the checkout; the console and the documentation are served from the
repository's files.

## Conventions

- **A change to behaviour comes with a test.** A change to a promise on the
  [security](security.md) page comes with its proof.
- **Layers.** A module imports only its layer or below. No cloud SDK outside `blobs.py` and
  `records.py`. No orchestrator. No sandboxes resource, and no way for a tenant to choose an
  image or a limit.
- **The platform reads no output.** It carries bytes; the package decides what a response is.
- **Short sentences and tables** in documentation. Every page answers one question.
- **The public surface is frozen within a major version.** The routes, the request and response
  shapes, the package contract and the environment variables change only in a new major.

## Documentation

Pages live in `docs/`, built by MkDocs with the Material theme into `harness_interface/docs`,
which ships in the wheel and is served at `/docs`. `mkdocs.yml` holds the navigation. The
catalog pages are generated by `scripts/catalog_verify.py` from the packages and the live
suite's logs; edit a package's `catalog.json`, not its page. Screenshots are under
`docs/assets/console`, recordings under `docs/assets/casts`.
