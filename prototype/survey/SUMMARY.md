# Harness survey — summary (23 harnesses)

Shapes: **A** = Anthropic Messages, **R** = OpenAI Responses, **C** = OpenAI chat completions. Providers: ant = api.anthropic.com, oai = api.openai.com, ds = DeepSeek. "Native" = text reaches the running turn at the next tool/step boundary (in-flight call finishes first, so "count 4" is still a pass). "Cancel+reprompt" = the turn is aborted and the text starts a new turn in the same live process. Per-harness detail: `<name>.md` in this directory.

## 1. Verdicts and tiers

**No harness has to be dropped.** All 23 passed ORCHID resume, a graceful stop that a resumed run could describe, and the counting steer test, so all reach `steered` — four only by cancel+reprompt, and harness-engineering only after we patch its source. Weakest, if the owner wants to cut: **aider** (no shell tool, so the literal counting task can't run; plain text; idle detection is a prompt-sniffing heuristic), **cheetahclaws** (terminal-rendered text; a multi-line task splits into several turns; rc 0 on API failure), **mimo** (unexplained ~2 min pre-start stalls in 3 of ~20 runs), **harness-engineering** (means maintaining our own harness.py).

## 2. Steering patterns

**P1 — Claude-style stream-json on stdin** (claude-code native; qwen-code cancel+reprompt). Adapter spawns `claude -p --input-format stream-json --output-format stream-json --verbose --replay-user-messages` / `qwen --input-format stream-json -o stream-json`, writes `{"type":"user","message":{"role":"user","content":T},"parent_tool_use_id":null}` (qwen also `"session_id":""`); qwen requires **first** line `{"type":"control_request","request_id":"init","request":{"subtype":"initialize"}}`, and a steer = `interrupt` then user message. **Done:** claude: a `result` arrives and `isReplay` user events ≥ messages sent (`queued_turn_count` unreliable); qwen: a `result` not caused by our interrupt, nothing pending. **Stop:** `{"type":"control_request","request_id":…,"request":{"subtype":"interrupt"}}`, wait for `result`, close stdin. **Background:** claude Bash `run_in_background` survives an interrupt (set `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`, untested).

**P2 — The CLI's own line-JSON RPC over stdio** (codex app-server, omp/pi `--mode rpc`, jcode `api-bridge --stdio`; all native). codex: `initialize{clientInfo,capabilities:{experimentalApi:true}}`, `initialized`, `account/login/start{type:"apiKey",apiKey}`, `thread/start|resume`, `turn/start{threadId,input:[{type:"text",text}]}`, steer `turn/steer{threadId,expectedTurnId,input}` ("no active turn to steer" −32600 → queue and `turn/start` after `turn/completed`); done = `turn/completed` with nothing queued. omp/pi: `get_state` (session id), `prompt`; omp steer `{"type":"steer","message"}`, pi `prompt` + `streamingBehavior:"steer"` (`disposition:"queued"|"started"`); done omp = `prompt_result` & queue empty, pi = `agent_settled` & no steer pending. jcode: frames `{"v":1,"id":N,"req":…}`: `hello`, `create_session|attach_session`, `send_message`, steer `soft_interrupt{session_id,content,client_id}`; done = `turn_done` & no soft-interrupt pending. **Stop:** codex `turn/interrupt`; omp `abort`; pi `clear_queue` then `abort` (queued steers survive an abort otherwise); jcode `cancel` then `jcode server stop --force` (cancel leaves a running bash alive). **Background:** jcode `api-bridge` spawns `jcode serve` (own pgroup, outlives the bridge) and needs `JCODE_RUNTIME_DIR` (mode 700) or bridge/daemon disagree on the socket path; an omp steer backgrounds the running bash as `bg_1`, which keeps running until the model cancels it.

**P3 — ACP (JSON-RPC 2.0 over stdio)** (goose, grok, minimax, gajae, hermes native; cline cancel+reprompt; qwen `--acp` native via a *client* method; openhands ACP works but racy — not recommended). Common: `initialize{protocolVersion:1,clientCapabilities:{}}`, `session/new{cwd,mcpServers:[]}` or `session/load`/`session/resume` (drop replayed `session/update`s), `session/prompt{sessionId,prompt:[{type:"text",text}]}`, `session/cancel{sessionId}` (notification); auto-answer `session/request_permission` with `{outcome:{outcome:"selected",optionId:"allow_once"}}`. Steer methods: goose `_goose/unstable/session/steer{sessionId,expectedRunId,prompt}` (run id from `session_info_update._meta.goose.activeRunId`); grok `_x.ai/interject{sessionId,text}` → `{status:"queued"}` (`_` prefix required); minimax `mcode/session/steer{sessionId,text}` → `{turnId,mode:"steered"}` (errors unless a prompt is admitted); gajae `_gjc/sdk/control{sessionId,operation:"turn.steer",input:{text}}`; hermes second `session/prompt` with `"/steer "+text` (returns `end_turn` at once — track the **main** prompt id); qwen: agent calls client method `craft/drainMidTurnQueue` after each tool result, reply `{"messages":[…],"hasQueuedPrompt":false}` within 2 s. Idle text → new `session/prompt` for all (goose/grok/hermes reject or misroute an idle steer; minimax steer never starts a turn; gajae idle steer accepted but nothing happens). **Done:** main `session/prompt` result `{stopReason:"end_turn"}` and no queued steer. **Stop:** `session/cancel`, wait for `stopReason:"cancelled"` (hermes returns error −32603 — treat as cancelled; openhands returns `end_turn`), close stdin. **Background:** gajae auto-spawns a setsid'd broker + session host that **survive SIGINT** (count went 3→16) — run `gjc sdk broker run --agent-dir $HOME/.gjc/agent` as a foreground child with `GJC_SDK_BROKER_AUTOSTART=0`, then `session/close` + SIGTERM the broker; cline spawns a detached hub daemon unless `CLINE_SESSION_BACKEND_MODE=local`.

**P4 — Local HTTP server inside the run** (opencode, kilo, mimo step-boundary; kimi-code native `:steer`). opencode/kilo/mimo: `serve --port 0|<free> --hostname 127.0.0.1`; wait for `… listening on http://127.0.0.1:N` (opencode/kilo print it; send nothing before — opencode hung >120 s; mimo: poll `GET /config`); `POST /session {}` → `{id}`; subscribe `GET /event` (SSE) **before** prompting; prompt and steer are the same call, `POST /session/{id}/prompt_async {"model":{"providerID","modelID"},"parts":[{"type":"text","text"}]}` (204; opencode needs `?directory=WS`; mimo rate limit 20/min). kimi: `kimi web --no-open --port P`, bearer `Authorization: Bearer $(cat $HOME/.kimi-code/server.token)`, `POST /api/v1/sessions {"metadata":{"cwd"}}`, `POST /sessions/{id}/prompts {"content":[…],"model":"__kimi_env_model__","permission_mode":"auto"}`, if it returns `status:"queued"` → `POST …/prompts/{pid}:steer {}` (empty body fails 50001); output by tailing `sessions/*/<id>/agents/main/wire.jsonl`. **Done:** opencode `session.status` idle; kilo idle **and** queue empty (ignore `session.turn.close{reason:"superseded"}`); mimo `session.idle` & no pending steer; kimi `GET /prompts` `active` and `queued` empty. **Stop:** `POST /session/{id}/abort` (kimi `:abort`), wait idle, SIGINT the server (kimi `POST /api/v1/shutdown`). **Client:** talk to 127.0.0.1 with **no proxy**. `kilo run --attach` works as an output pump but SIGINT to it doesn't stop the server turn; opencode `--attach` drops its final events (race) — translating SSE parts into run-format NDJSON keeps one report parser.

**P5 — Local WebSocket gateway** (nanobot, opensquilla; native). nanobot: `nanobot gateway` with `channels.websocket` on 127.0.0.1; connect `ws://127.0.0.1:P/?client_id=hi` with `proxy=None` (the `websockets` client honours HTTPS_PROXY); `ready{chat_id}`; resume `attach{chat_id}`; task `{"type":"message","chat_id":C,"content":T,"workspace_scope":{"project_path":WS,"access_mode":"full"}}`; steer = another `message` on C; done = `turn_end` then drain 1 s; stop = `content:"/stop"` ("Stopped N task(s)." and no `turn_end`). opensquilla: `gateway run --port P`, `ws://…/ws`, `connect.challenge` → `connect{minProtocol:1,maxProtocol:3,role:"operator",scopes:["operator.admin"]}`, `sessions.create{agentId:"main",kind:"cli"}` → `{key}`, `sessions.messages.subscribe`, `sessions.send` → `turn_id`; steer `sessions.steer.v2{key,message,expected_turn_id,client_request_id,client_message_id}` → `disposition:"steering"`; done `session.event.done`; stop `sessions.abort`. **Background:** a gateway process each (killpg in `finally`); nanobot leaves `run/gateway.json` in `.home` (singleton guard — a stale one blocks the next start); opensquilla ready in ~5 s.

**P6 — REPL + SIGINT** (aider, cheetahclaws; cancel+reprompt; an interrupt throws away the reply in flight — aider drops all its edits). Adapter pipes stdin, parses terminal text; busy/idle from the prompt (aider trailing `> `, fails without `--no-fancy-input`; cheetahclaws `╭─ CheetahClaws ●` … `╰─` box). Steer while busy = SIGINT once, wait for prompt, write the text as one line. cheetahclaws: also SIGTERM the pgroup of every tool child (its Bash tool runs commands under `start_new_session` and ignores the SIGINT); never 3 SIGINTs within 2 s (`os._exit(1)`); disable `AskUserQuestion` (reads stdin mid-turn). **Done:** idle & nothing queued. **Stop:** aider close stdin; cheetahclaws `/save <path>` + `/exit`.

**P7 — SDK in-process** (openhands, harness-engineering-patched). openhands: openhands' own venv python; `setup_conversation(uuid, NeverConfirm(), …, env_overrides_enabled=True)`; `conv.run()` in a thread, a stdin thread calls `conv.send_message()` (effective next step); done = `run()` returns & nothing pending (re-run if a steer came late); stop `conv.pause()` (rc 0, ~1.4 s). Background: a `tmux -Lopenhands` server (when tmux exists) survives killpg. harness-engineering: its own stdin reader thread; EOF → `os.kill(self,SIGINT)`.

**P8 — Hook bridge** (deepseek-harness). Adapter writes each steer atomically to `/tmp/dsh-steer/<ns>.msg`; a mounted `dsh-hooks-claude-code` row runs `steer_hook.py`: PostToolUse prints `{"hookSpecificOutput":{"hookEventName":"PostToolUse","additionalContext":…}}`, Stop prints `{"decision":"block","reason":…}`. Steers never appear in `--json` stdout (only in the session log). Done = process exit (`turn_end` completed). Stop = killpg SIGINT the dsh child (rc 130). Unhandled: a steer written after the last Stop hook fired is not delivered — the adapter should check for undrained files at exit (untested).

## 3. What the server and contract must provide

Required by the surveys (fit the stated contract if its meanings are pinned down):
- **Stdin for steered runs.** Line 1 must be **one-line compact JSON** (today's server sends `indent=2`, which breaks harness-engineering's `read -r`; pi's adapter accumulates lines until they parse). Keep stdin open until the user ends the session; **EOF before "done" = graceful stop**. The adapter exits on its own done condition and must not wait for EOF (claude, cheetahclaws, grok, omp, pi all do this). Several surveys note today's non-interactive mode closes stdin right after line 1, which would stop a steered run at once.
- **SIGINT to the run's process group**, with run.sh `exec`-ing a single adapter process. Every adapter puts its CLI and daemons in **their own session** (`start_new_session=True`) and turns SIGINT into the CLI's own cancel. Plain group SIGINT is wrong for many: it kills codex app-server mid-request, goose acp (rc −2, loses the last tool result) and cline ACP (dies with no reply); hermes and openhands ACP ignore it and keep working; the gajae broker and jcode daemon survive it. With `--init`, tini forwards only to its direct child unless `-g`/`TINI_KILL_PROCESS_GROUP=1` (not verified in our image), so set it, or make the adapter PID 1's direct child.
- **Stop timeout:** observed graceful stops 0.03–3.1 s, outliers: claude 2.1.42 35 s (background bash), hermes ACP + SIGINT ran on 87 s. SIGINT → wait ~15 s → SIGKILL the container; adapters must killpg their children in `finally`.
- **Early, atomic HI_OUTPUT**; the server reads `$HI_OUTPUT` even after a kill and takes the last complete write (tmp + rename). Ids can be chosen before launch for claude `--session-id`, grok `-s`, qwen `--session-id`, pi, openhands `--resume <uuid4>`, aider, opensquilla CLI, harness-engineering; elsewhere the id arrives within ~0.3–5 s (`session/new`, `get_state`, `POST /session`, first event).
- **Stable workspace path** and persistent `.home` across runs: resume is cwd-scoped in claude 2.1.42, dsh, pi `--session-id`, grok, qwen, kimi, codex rollouts.
- **Loopback inside the container**: opencode, kilo, mimo, kimi, nanobot (2 ports), opensquilla, gajae broker; jcode uses unix sockets in `/tmp`. The server must set **`NO_PROXY=127.0.0.1,localhost`** and own NO_PROXY entirely (the host's NO_PROXY listed api.anthropic.com, which bypassed the proxy for pi). Untested inside the real sandbox.
- **Writable `/tmp`**: jcode `JCODE_RUNTIME_DIR` and `/tmp/jcode-bg-tasks`, mcode config, dsh patch/hooks/queue, `/tmp/claude-<uid>`, `/tmp/kilo`, `/tmp/tmux-0`. A read-only root is fine (goose uses XDG dirs).
- **Exit codes are not status**: rc 0 on failure for aider, cheetahclaws, mimo (401), nanobot, openhands, gajae (SIGINT), pi json/rpc. Status always from events.

Contract changes the surveys ask for, beyond `run.interrupt` / stdin lines / SIGINT / `{answer,status,resume,usage,cost_usd}`:
1. **`steers`** — count of steer lines the CLI accepted. Late steers race with "done" (codex "no active turn", minimax throws, kimi 40402); adapters re-issue them as new turns, and the server needs the count to spot lost lines.
2. **`status` enum** — surveys use ok/fail/interrupted/stopped/cancelled/paused. Proposed: **`ok | fail | stopped`** (stopped = by the user, resumable), plus `running` for the early write. Every current report.py maps an interrupt to `fail` or `ok`.
3. **Per-run `usage`/`cost_usd`** — cumulative totals must be diffed against the start-of-run value: claude 2.1.304 `total_cost_usd`, goose `complete` & `usage_update.cost`, cline manifest, hermes `state.db`, openhands `base_state.json`, codex `thread/tokenUsage .total`, cheetahclaws `/cost`.
4. **Provider API shape (`HI_PROVIDER_API` = anthropic-messages | openai-responses | openai-chat)** — URL + key isn't enough to choose: grok `api_backend`, omp `api:`, kimi `KIMI_MODEL_PROVIDER_TYPE`, qwen `--auth-type`, goose provider, aider/openhands litellm prefix, cline `CLINE_PROVIDER`, nanobot/opensquilla provider. Several surveys invent per-folder knobs for it (`OMP_API`, `HI_API_BACKEND`, `QWEN_AUTH_TYPE`).
5. **`files` may target `.home/…`** — instructions belong where the CLI reads user-level files: claude `.home/.claude/CLAUDE.md`, codex `.home/.codex/AGENTS.md`, gajae `.home/.gjc/agent/AGENTS.md`, nanobot `.home/.nanobot/workspace/USER.md`; otherwise the folder writes into the user's tree. openhands and opensquilla must **prepend** instructions to the task (their AGENTS.md is ignored), so line 1 has to carry them.
6. *(Optional)* **Key delivery off the environment** — any env key is visible to the model's shell (printenv showed `CODEX_API_KEY`, `HI_PROVIDER_KEY`, `MCODE_PROVIDER_API_KEY`). codex's adapter reads it on fd 3 (`3<<<"$HI_PROVIDER_KEY"`, `env -u`); minimax `env -u` after writing its config. A server-provided fd or 0600 `/tmp` file would make this generic.

## 4. Folder template

- **harness.json:** `provider` (default), `run.interrupt:"steered"`, `run.stdout:"application/x-ndjson"` (aider and harness-engineering `text/plain`), `run.env`: `HOME={workspace}/.home`, the quiet switches from §3, `NO_PROXY=127.0.0.1,localhost`, `PYTHONUNBUFFERED=1` for Python CLIs; `files`: instructions where the CLI really reads them (§3.5).

For a single-shot `continued` fallback, run the CLI with `</dev/null` (codex, qwen, kilo, omp, dsh, harness-engineering tools read or inherit stdin).
- **adapter.py responsibilities:** (1) SIGINT/SIGTERM handlers set a stop flag; (2) read line 1 (tolerate pretty-printed JSON); (3) choose or obtain the resume id and write `{"resume":id,"status":"running"}` atomically **before** the first model call; (4) spawn the CLI and its daemons with `start_new_session=True`, cwd = workspace, stdin piped, no proxy for loopback; (5) a stdin thread decodes each later line with `json.loads` → steer if busy, new prompt if idle or refused; count `steers`; (6) pass the CLI's events to stdout, flushed (translate SSE/WS into NDJSON); (7) done = the pattern's condition and nothing queued, then a graceful close; (8) stop (flag, or EOF while busy) = the CLI's cancel, wait ≤10 s, close stdin, killpg children in `finally`; (9) final HI_OUTPUT: answer, status ok|fail|stopped from **events**, per-run usage/cost deltas, steers; clean any workspace residue the run created.
- **report rules (if kept separate):** `signal(SIGINT, SIG_IGN)` (or `(trap '' INT; exec python3 report.py)`); write early, rewrite at the end; never status from the exit code; strip noise from the answer (aider `^C again to exit`/git nag, cheetahclaws boxes, hermes `⏩ Steer queued`, opensquilla `[[reply_to_current]]`, ACP replay chunks).
- **artifacts:** map to each CLI's HOME paths (listed per survey); never ship key-bearing configs (openhands `agent_settings.json`, aider `.env`).
- **URL `/v1` rule:** no `/v1`: aider `anthropic/`, claude, goose `ANTHROPIC_HOST`/`OPENAI_HOST`, harness-engineering, pi anthropic, kimi anthropic, qwen anthropic, openhands anthropic.
