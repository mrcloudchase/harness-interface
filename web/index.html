How it works

Three things, in the order you meet them. Any OpenAI SDK works unchanged.

1Bring your providers

Anthropic, OpenAI, DeepSeek, anything with the same shapes. A key is sealed on arrival and opened only inside the gateway, for one upstream call at a time. It never enters a sandbox.

2Bring your harness packages

A folder: how to install the CLI, how to run one turn, what to return. Fork one of twenty-two verified packages from the catalog, or upload your own.

3Ask through the Responses API

model names a harness. Continue a session with previous_response_id, stream the output, steer or cancel a running turn, browse the workspace after it.

# a provider and a package in place, that is the whole request curl -s https://harnessgateway.ai/v1/responses -H "Authorization: Bearer $KEY" \ -H 'content-type: application/json' \ -d '{"model": "claude-code", "input": "Add a test for the parser and run it."}'
# or any OpenAI SDK, unchanged from openai import OpenAI client = OpenAI(api_key="hg_…", base_url="https://harnessgateway.ai/v1") r = client.responses.create(model="codex", input="Fix what failed.") print(r.status, r.output_text)

Twenty-two harnesses, verified

Each package was run through nine live checks against a real provider: make a file, recall it next turn, the archive holds it, a turn streams, a steer is answered, a running turn cancels, the trace records it all, a stateless request leaves nothing behind.

What you get

Sandboxed by construction

A fresh container per turn, no capabilities, a read-only root, the tenant's own uid and ceilings, and a door that tunnels only to the hosts the package names.

The workspace, in the app

Every turn ends with a snapshot. Browse the files the agent made, read them in place, download the archive, continue the session.

The rodeo

One task, several harnesses, out of the chute side by side. Pick the winner. The leaderboard remembers which harness earns your work.

The complete record

Every request, steer, cancel and response in the trace; every provider exchange captured; usage metered per turn.

Your team

Accounts with email, GitHub or Google sign-in. Owners invite members by email, mint keys per place a key is used, and revoke the one that leaks.

Hosted or yours

One image, four roles. Records in SQLite or Postgres, blobs in a directory or any S3 store, no cloud SDK anywhere else. The same code is harnessgateway.ai and your own box.

Deploy in one command

A Linux server or Docker Desktop on a Mac. The first boot makes the keys and prints them once.

docker run -d --name hg -p 127.0.0.1:8000:8000 \ -v /var/run/docker.sock:/var/run/docker.sock -v hg:/data ghcr.io/mrcloudchase/harnessgatewayai docker logs hg # the deployer key, your tenant, your API key

Then open http://127.0.0.1:8000/app. Deploy has the fleet shape, TLS and workers on other machines.
